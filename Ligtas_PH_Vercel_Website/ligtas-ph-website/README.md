# Ligtas PH — Project Landing Page

A responsive, static landing page for the Ligtas PH student venture concept. Built with plain HTML, CSS, and JavaScript so it can be published directly to Vercel without a build step.

## Preview locally
Open `index.html` in your browser.

## Publish to Vercel
1. Extract the ZIP file.
2. Create a new GitHub repository and upload the files in this folder (`index.html`, `styles.css`, `script.js`, `vercel.json`, and this README).
3. Sign in at https://vercel.com/ and choose **Add New → Project**.
4. Import the GitHub repository.
5. For a plain static site, leave the framework preset as **Other** and leave Build Command and Output Directory empty (or use `.` as the output directory if Vercel requires one).
6. Click **Deploy**. Vercel will provide a public URL you can submit for your class.

## Important
This is a concept website for a student project, not a live emergency service or a released mobile application. The phone UI is illustrative. The preparedness checklist works in the browser but does not save progress after refreshing. The site links to PAGASA for official weather information. Do not present this site as an official government service.
